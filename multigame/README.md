多游戏集合 (Python)

说明:
- 这是一个包含多个主流小游戏的集合，使用 `tkinter` 创建 GUI 启动器并包含若干独立游戏模块。
- 提供的小游戏：井字棋 (Tic-Tac-Toe)、猜数字、猜单词 (Hangman)、二十一点 (Blackjack)、记忆翻牌 (Memory)、扫雷 (Minesweeper)、贪吃蛇 (Snake)。

运行:
1. 确保 Python 3 已安装。
2. 在终端运行：

```bash
cd /Users/anastasio/Documents/UniversityWork/DataStructureAI/multigame
python3 main.py
```

依赖:
- 仅使用标准库 `tkinter`，无需额外包（如需更高级图形可安装 `pygame`）。

说明: 这个项目为教学示例，包含多个小游戏的实现和一个统一的启动界面。
