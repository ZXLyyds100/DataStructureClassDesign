# 游戏图片资源说明

将您的游戏图片放在此目录下，游戏会自动加载。

## 贪吃蛇游戏图片

贪吃蛇游戏支持自定义图片，请准备以下图片文件（PNG 格式）：

1. **snake_head.png** - 蛇头图片
   - 推荐尺寸：25x25 像素（或任何正方形尺寸，游戏会自动缩放）
   - 建议：可以使用一个向右的蛇头图案

2. **snake_body.png** - 蛇身图片
   - 推荐尺寸：25x25 像素
   - 建议：可以使用蛇身体的鳞片纹理或简单方块

3. **snake_food.png** - 食物图片
   - 推荐尺寸：25x25 像素
   - 建议：可以使用苹果、樱桃等水果图案

## 其他游戏图片（可选）

### 记忆翻牌游戏

在 `memory.py` 中也预留了图片加载功能，您可以准备：

- **card_0.png** 到 **card_7.png** - 8张不同的卡牌图案
- **card_back.png** - 卡牌背面图案

### 扫雷游戏

- **flag.png** - 旗帜图标
- **mine.png** - 地雷图标

## 图片获取建议

1. **自己绘制**：使用图像编辑软件（如 Paint、Photoshop、GIMP）创建
2. **免费图标网站**：
   - [Flaticon](https://www.flaticon.com/)
   - [Icons8](https://icons8.com/)
   - [Freepik](https://www.freepik.com/)
3. **表情符号转图片**：可以截图系统表情符号使用

## 注意事项

- 所有图片必须是 **PNG 格式**
- 建议使用透明背景的 PNG 图片以获得最佳效果
- 图片会被游戏自动缩放到合适的大小
- 如果图片文件不存在，游戏会使用默认的彩色方块渲染
